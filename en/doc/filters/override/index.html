Override

This filter allows you to change a field of a Message, before sending it to the next filter. Templates with Sprig functions can be used.

Parameters

ParameterTypeDefaultDescription
nameSTRINGemptyname of the field to change (supports templates)
valueSTRINGemptynew value to assign to the Message’s field specified (supports templates)
... | override(name="description", value="{{ .title }}") | ...

Output

The propagated Message will be identical to the original, with only the specified field changed.
